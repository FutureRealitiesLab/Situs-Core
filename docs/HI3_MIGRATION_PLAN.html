Hyper-Irrealismus III auf Situs Core umstellen

Hyper-Irrealismus III bleibt vorerst auf dem aktuellen Stand (Godot 4.6, SYSTEM/). Dieser Plan gilt, sobald Situs Core in Godot 4.7 getestet und als v1.0.0 getaggt ist.

Befund

  • Team-Szenen unter _scenes/ rufen keine Core-API direkt auf (per grep geprüft). Sie hängen nur an scene_hooks.gd und damit an SceneManager.on_team_scene_ready(). Diese Methode gibt es im neuen Core weiter.
  • Außerhalb von SYSTEM/ verweisen nur project.godot, README.md, _anleitungen/*.md und Kommentare in _scenes/team_template/scene_info.cfg auf res://SYSTEM/.
  • _scenes/team_template/ und scene_registry.gd bleiben unverändert. Die Team-Szenen verweisen per UID auf scene_hooks.gd in diesem Ordner.
  • Aus SceneManager nach SceneLoop verschoben: timer_tick, auto_advance, toggle_auto_advance, go_to_scene. Team-Code nutzt sie nicht.

Ablauf

Alles auf einem eigenen Branch. master bleibt unberührt, bis alle Tests grün sind.

  1. Branch und Remote anlegen

    git checkout -b migrate/situs-core
git remote add situs-core https://github.com/FutureRealitiesLab/Situs-Core.git

  2. Alten Core entfernen, neuen als Subtree einbinden

    git rm -r SYSTEM/
git commit -m "chore: SYSTEM/ entfernt (ersetzt durch Situs Core)"
git subtree add --prefix=addons/situs_core situs-core dist --squash

  3. Meta Quest entfernen

    • addons/godot_meta_toolkit/ löschen
    • openxr_action_map.tres: oculus/touch_controller samt Bindings entfernen
    • export_presets.cfg.template: Meta-Quest-Preset und meta_*-Optionen entfernen
    • project.godot: openxr/extensions/meta/... entfernen
    • addons/godotopenxrvendors/ bleibt (HTC)

  4. project.godot anpassen

    • config/features: ("4.7", "GL Compatibility")
    • run/main_scene="res://addons/situs_core/core/main.tscn", die Zeile config/main_scene= entfällt
    • Autoloads GameState, NetworkManager, SceneManager auf addons/situs_core/...
    • Danach SceneLoop eintragen. Der Autoload muss nach SceneManager stehen.
    • [editor_plugins]: res://addons/situs_core/plugin.cfg aktivieren
    SceneLoop="*res://addons/situs_core/modules/modul_scene_loop/scene_loop.gd"

  5. Pfade in Doku und Kommentaren

    res://SYSTEM/avatar/... wird zu res://addons/situs_core/avatar/.... In README.md und _anleitungen/*.md ersetzt du SYSTEM/ durch die neuen Pfade (core/ für main, scene_manager, cam_dolly, net_info_board) und entfernst die Quest-Hinweise.

  6. In Godot 4.7 öffnen

    Migrationsdialog bestätigen und das Output-Panel auf Deprecations prüfen. Dabei entstehen .uid-Dateien. In HI-III steht *.uid in der .gitignore; entscheide, ob das so bleibt.

  7. Testen

    • F5: Startmenü, Server und FPS-Spieler, Szenen laufen im Loop (Timer, N, L)
    • F6 auf einer Team-Szene
    • Alle Szenen aus scene_registry.gd einmal durchschalten
    • Standalone am Desktop mit Q und E
    • APK „Android – HTC Focus 3" bauen und auf der Focus Vision prüfen: Co-Location, Avatare, Szenenwechsel

  8. Nach master mergen

    Erst wenn der Test in Schritt 7 grün ist.

Updates später

git subtree pull --prefix=addons/situs_core situs-core dist --squash

Änderungen am Core entstehen im Situs-Core-Repo, danach wird dist neu erzeugt. Wer lokal in addons/situs_core/ von HI-III ändert, bekommt beim nächsten Pull Konflikte.
